# Reproduction

This directory is organized around the visible result families in the paper.

Start here:

- [`overall/README.md`](overall/README.md): top-level orientation and the small
  set of visible figure outputs
- [`validation/README.md`](validation/README.md): validation and all-model
  comparison outputs
- [`targeted_comparison/README.md`](targeted_comparison/README.md): targeted
  smoothing comparisons, heatmaps, and selected comparison figures
- [`broad_sweep/README.md`](broad_sweep/README.md): broader sparsity/smoothing
  sweeps

The intent is not to document every intermediate file in the archive. The focus
is on the PNGs, tables, and visible result families that actually appear in the
paper, together with the commands needed to inspect, rerender, or rerun the
corresponding workflows.
